## Código em linhas e blocos de código

O comando `git status` mostra o estado atual do repositório.

O comando `git add .` adiciona os arquivos modificados á *staging area*.

O comando `git commit - m "Mensagem de comentário"` registra as alterações com uma memsagem.

O comando `git push` envia os arquivos para a nuvem.

```
git status 
git add . 
git commit -m "Mensagem de comentário"
git push 

```
